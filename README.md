# SHUBO — 酒母の小宇宙

オフラインで動く、1ファイルの3D酒母ゲームです。

**ゲーム本体：`dist/index.html`**

PCではファイルをブラウザで直接開けます。スマートフォンでは配信用URLからの起動を推奨します。ファイル直接起動の可否はOS・ブラウザのローカルHTMLの扱いに依存します。ゲーム本体は通信なしで実行できます。

ローカルプレビュー：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory dist
```

`http://127.0.0.1:8768/` を開いてください。

- 水・米・米麹・酵母で世界を仕込む
- 探索艇、酵母、細胞内部へ視点を切り替える
- 温度と酸性環境を調整し、発酵を安定させる
- 糖を集めて出芽、生物を観察して図鑑へ記録
- タッチ・キーボード・一時停止・動きを減らす設定
- WebGL非対応時は2Dモードへ切り替え

仕様と科学上の表現範囲は `docs/SPECIFICATION.md`、検証結果は `docs/VERIFICATION.md` を参照してください。

## 継続時の起点

正本はこのフォルダの `dist/index.html`。既存のSAKE ART TOKYOサイトやSHUBO RUNとは別の新作です。実行時依存ファイルを増やさず、HTML一枚の条件を保ってください。

仕込みの途中・名前付き菌株・育成記録・設定・図鑑・最高記録を端末内に保存します。上部の「育成」からリアル／キャラクター切替、命名、セーブ書き出し／読み込みができます。離れている間は進行しません。

今回の追加とアプリ化の設計案は `docs/CARE_UPDATE.md`。実装はローカル段階で、既存の配信URLには未反映です。

## 素材投入の演出（2026-09-16）

水の波紋、蒸米の湯気、金色の麹胞子、酵母アンプルの新規画像と短い演出を追加。仕込み画面のアニメーションは初期ON、設定は保存されます。投入済みの素材もタップして再生できます。

動作・上限・検証範囲は `docs/INGREDIENT_EFFECTS.md`。HTML内に新画像を埋め込み、実行時は引き続き1ファイルで完結します。

## 発酵世界の場所と成長（2026-09-16）

このタスクは育成・観察と世界観を深めます。シューティングはユーザーが分岐する別タスクの範囲です。

「世界の地図」から米の浅瀬・麹の回廊・酵母の入り江を眺められます。投入した素材が世界に現れ、育成に応じて糖の光・酵母の集まり・気泡が変わります。既存の途中セーブ、アニメーションOFF、2D表示にも対応します。

仕様と検証範囲は `docs/WORLD_BUILDING.md`。今回もローカルの更新で、配信URLには未反映です。
