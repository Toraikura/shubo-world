# 世界観側の進め方と今回の更新

2026-09-16。ローカル実装。既存の配信URLには未反映。

## ユーザーが決めた方向

シューティングゲームはユーザーが分岐させる別タスクで制作する。このタスクは酒母の世界観・育成・観察を深める。探索艇は観察用のまま残す。このタスクから別タスクを作成・指示したり、戦闘を追加したりはしていない。

この作品の軸は「一粒の米から、自分の発酵世界を育て、その中の生命を眺める」。静かな暗い水、白い米、青緑の菌糸、紫の酵母、金色の糖を場所と働きに対応させる。

## 今回実装したこと

### 覚えられる3つの場所

- **米の浅瀬**：白い蒸米の島。でんぷんの供給源。
- **麹の回廊**：米麹の菌糸をたどる、青緑の構造。酵素の働きを金色の流れで表す。
- **酵母の入り江**：代表的な酵母を集めた水域。仕込みが進むと細胞の集まりと気泡が現れる。

「世界の地図」から、投入済みの素材に対応する場所へ観察カメラを向けられる。場所選択はプレイヤー移動・図鑑登録・報酬を発生させない。細胞の中からも全景へ戻れる。既存のパネル外クリック、Escape、フォーカス管理に接続した。

### 仕込むと、景色が現れる

未投入の米・米麹・酵母は世界に表示しない。水を加えると水域と浮遊粒子が現れる。素材の投入順は従来どおり自由。

糖の流れには水・蒸米・米麹が必要。酵母を迎えると、まず出芽形態を含む1体の代表モデルを表示する。発酵進捗とその仕込みの出芽回数に応じて、最大23体の代表モデルが見える。画面上の数は菌数の推定ではない。

「糖の灯り」「入り江に生命が集う」「泡の星空」という景色の変化を表示する。糖化と発酵は同時に進む。章名は景色の説明で、実際の醸造工程を順番に置き換えるものではない。

### 保存と操作

景色は既存の素材・発酵進捗・出芽回数から導出する。セーブ形式の変更や追加報酬はない。同じ途中セーブから再開すれば同じ景色になる。観察カメラも従来の保存で復元する。

アニメーションOFF・OSの動きを減らす設定では、糖の移動や気泡の浮上は止まる。育成の数値と景色の状態変化は従来どおり進む。明示的な一時停止・パネル表示・背景タブでは育成も止まる。

2D表示も同じ素材と成長状態を使う。既存の世界形状の一部をカメラで投影するため、地図から眺める場所も変わる。

## 科学と創作

- 米麹に由来する酵素による糖化と、酵母による発酵を区別する。
- 菌糸と胞子の冠は米麹の形態を拡大した展示。酒母の中で胞子の森が育つ説明にはしない。形を発酵とともに伸ばす処理も追加しない。
- 酵母の集まる入り江、光る糖の道、地形・色・縮尺・代表モデル数は観察と遊びの表現。
- 気泡の量は発酵の進捗だけに連動する。出芽それ自体を気泡の原因にしない。
- ゲームの成功条件・温度変化・所要時間は既存のゲームモデルを維持する。

科学の参照元は `SPECIFICATION.md`、過去の育成の仕様は `CARE_UPDATE.md` を参照。

## 負荷の上限

既存の静的形状に分類値を付け、描画時の値で表示を切り替える。素材投入や進捗変化のたびに形状を再構築しない。非表示の形にも頂点処理は残るため、これだけで性能改善を保証するものではない。

- 世界の静的形状数と三角形数は変更なし：リアル4,962モデル・987,512三角形。キャラクター5,957モデル・1,266,112三角形。
- 新しい糖の流れは最大32粒、気泡は最大24粒。既存の220個上限の動的バッファを再利用する。
- 最も多い検証条件で貨物・粒子用146個、プレイヤー用25個。細胞内の形状は変更なし。
- 外部通信や外部素材は追加していない。単一HTMLのまま。
