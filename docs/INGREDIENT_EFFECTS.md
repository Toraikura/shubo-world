# 素材を迎える演出

2026-09-16。既存ゲームのローカル更新。既存の配信サイトには未反映。

## 操作

「世界をつくる」で仕込みパネルを開き、素材をタップする。

| 素材 | 追加した表現 |
|---|---|
| 水 | 新しい注水画像、流れ、水滴、広がる波紋 |
| 蒸米 | 新しい蒸米画像、ゆっくり立ち上る白い湯気 |
| 米麹 | 金色のふるいの新画像、単一の色付き霧と少量の舞う胞子 |
| 酵母 | オリジナルのガラスアンプル画像、上から入る動き、酵母を迎える光 |

仕込みパネル内と、その背後の世界に短いエフェクトを表示。投入済みのボタンも押せるので、素材を重複投入せずに見返せる。続けて押した素材は最大4件の順番待ちで再生し、ゲーム開始やパネルを閉じる操作は待たせない。

麹の散布は製麹工程のイメージ。酒母に加えるのは、麹菌を育てた米麹であることを本文に明記。アンプルと光は投入を示す演出で、製造操作の手順を再現するものではない。

## アニメーション設定

- 初期値はON。旧セーブで設定がなければONとして読み込む。
- 仕込み画面と環境調整の両方から切替でき、設定を端末に保存。
- OFFで投入エフェクトと待ち行列を終え、最後の素材の画像を静止表示する。
- OFFで環境の自動アニメーションと自動周回カメラも停止。ゲーム時計・プレイヤーの移動・手動のカメラ操作は継続。
- OSまたはゲームの「動きを減らす」が有効なら静止表示。ONのチェックは保ち、実効状態を「ON · 静止表示」と表示する。
- 明示的一時停止、画面非表示ではエフェクト時間も止まる。
- 仕込みパネルはゲーム時計を停止するが、素材エフェクトには独立した時計がある。

## 処理量

- 素材演出は各3.2秒、最大30fpsで更新。
- 画像アトラス1枚：1254×1254、JPEG 279,203バイト。HTMLへbase64で埋め込み。
- 湯気と金色の霧は同じ96×160のCanvasテクスチャを再利用。毎フレーム霧を生成し直さない。
- 水滴20、胞子18、到着する光12の固定上限。粒子の配列やDOMを無制限に増やさない。
- エフェクト用の世界Canvasは最大960×600。パネル内Canvas幅は最大640。
- OFF／停止中は自動描画の間隔を150msに落とす。カメラ状態の変化や直接操作はその制限を外す。
- 3Dの既存ジオメトリ数は変更なし。実機のFPS・消費電力は未測定。
