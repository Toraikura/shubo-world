# SHUBO — 酒母の小宇宙

## 体験の仕様

米・水・米麹・清酒酵母から小さな世界をつくり、その生態系を育てながら探索する、1人用の3Dゲーム。1回約5〜8分。モバイルブラウザを主対象にPCでも操作する。

1. **世界を育てる**：水・蒸米・米麹・酵母を順に投入し、育成を開始。温度と酸性環境を調整し、ときどき櫂入れする。
2. **探索艇**：後方カメラで米の群島を巡る。タッチスティックまたはWASDで移動、上下ボタンまたはQ/Fで浮上・潜降。主要構造を観察して図鑑に記録。
3. **酵母になる**：金色の糖を集め、6個で出芽。3回の出芽でコロニーが成長。出芽は活性と発酵を助ける。
4. **細胞の中**：酵母の細胞壁、リン脂質二重層、選択的な膜輸送、リガンド結合、核、液胞、小胞体、リボソーム、アクチンとミオシンV、小胞、ミトコンドリアとクリステ・回転機構を観察。

## 成功・失敗

- 成功：8分以内に発酵100%、酵母活性55%以上、汚染圧45%未満。
- 失敗：汚染圧95%以上、酵母活性2%以下、または8分経過。
- 85秒に水温+7、160秒に酸性環境-25、245秒に水温+5の環境変化がある。実時間は時間速度に従う。
- 結果にはスコアと最高記録を表示。再仕込み、または同じ世界の自由探索が可能。
- 所要時間・数値・環境イベントはゲーム設計上のモデル。実際の醸造工程の予測ではない。

## 科学の扱い

- 米のでんぷん → 麹由来の酵素による糖化 → 酵母によるアルコール発酵、を別々の役割として示す。
- 酒母中の主役は米・菌糸・酵素・出芽酵母。麹菌の胞子頭は形態を拡大した展示。酒母の中で胞子頭の森が成長するという説明はしない。
- 清酒酵母の小胞輸送は主にアクチンとミオシンV。動物細胞のキネシン輸送を中心機構にしない。
- 細胞壁と細胞膜を別の構造として表示。細胞膜は2層の密なリン脂質頭部と、対をなす疎水性尾部。
- 乳酸の働きは汚染微生物が増えにくい環境づくり。無差別な殺菌兵器とはしない。
- 光・色・比率は観察用の演出。酵母の操作移動はゲーム表現。ミトコンドリアのATP回転モデルはアルコール生成機構ではない。
- 安定した酒母と完成した日本酒を区別する。

## 操作とアクセシビリティ

- 1本指ドラッグ：見回す／周回。2本指ピンチ・ホイール・＋−：拡大縮小。
- WASD：移動。Q/F：上下。矢印：見回す。E：観察・出芽・櫂入れ。1〜4：視点。R：カメラ。Space：一時停止。
- 全ボタン・スライダー・図鑑はキーボード対応。フォーカス枠、ダイアログの背景inert、Tab循環、Escapeでパネルを閉じる。
- モバイル・タブレット幅でも操作スティックを表示する。
- パネル・結果画面・非表示タブでは進行を停止。OSの動きを減らす設定を初期値として取り込み、独立した切り替えも用意。
- 音は明示的にオンにしたときだけWeb Audioで合成する。

## 実装境界

- 実行用成果物は `dist/index.html` 1ファイル。HTML/CSS/JavaScript/GLSL/形状生成/音をインラインに保持。
- 外部ライブラリ、フォント、画像、動画、ダウンロード素材、CDN、API、計測、外部通信は不要。
- 参考資料のリンクは手動で開いた場合だけネットワークを利用する。
- WebGL 1 + ANGLE_instanced_arrays。インスタンス数・メッシュは固定上限。重い衝突判定や総当たり群行動は行わない。
- 描画は通常4形状と2動的バッチ、背景と縮小ブルームの4パス。GPUリソースはシーン切替で破棄し、再構築する。
- 画面解像度は通常DPR1.45上限、軽量1.0・精細1.8。自動モードでは負荷が継続すると内部解像度を下げる。
- 外部アセットを使わず、シェーダーの表面模様・霧・光の筋・縮小ブルームで水中と蛍光を表現。
- WebGLやインスタンシングが使えない場合は2D観察モードへ移行。育成・図鑑・移動ロジックは共有する。
- 保存するのは端末内の設定、観察記録、最高スコア。進行中の仕込みは再読み込みで初期化する。
