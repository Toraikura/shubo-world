# キャラクター表現と育成の土台

2026-09-15。今回の更新はローカルの試作。既存の配信URLには未反映。

## 今回実装したこと

- 上部の「育成」から、名前を持つ同じ菌株へ戻れる。
- リアル／キャラクターを切替。酵母の楕円形と出芽、麹の枝分かれを残し、キャラクター表示は表情と色を加える。細胞内部は観察表示を共用。
- 仕込み中に集めた糖・実際の出芽・安定した仕込みを通算で記録。最近6回の結果を保持する。
- 仲間は最大3体。プレイヤーの後を追う。3体完成後に出芽を連打して、架空の出芽や発酵報酬を稼ぐことはできない。
- 現在の仕込み、素材、糖の回収状態、位置、視点、環境値を保存。起動時は安全に一時停止し、その視点から再開。
- 5秒ごと、命名・出芽・結果などの節目、画面離脱時に保存。直前の正常なセーブを1世代保持。保存失敗は手帳に表示し、再試行の間隔を保つ。
- JSONで書き出し／読み込み。読み込みは内容の確認後にユーザーが入替ボタンを押して適用。サイズと形式を検証し、数値・文字列を制限する。
- 従来の設定・図鑑・最高記録を移行。旧保存キーは削除しない。
- 画面を閉じている間は進行しない。日数による全滅や減点はない。

親子が歩いて追従する動き・顔・発光はゲーム表現。酵母が自力で泳ぐという説明ではない。自由探索での糖や出芽は、仕込みの通算記録に加算しない。

## スマホ本体で処理する構成

現行版もJavaScriptの計算とWebGL描画をプレイヤーの端末で実行している。サーバーで菌の世界を常時シミュレーションする構成ではない。

- 単体HTML：引き続き試遊・配布の本体。
- ホーム画面版：将来、インストール情報とService Workerを追加。単体HTMLがオフライン動作することと、配信URLをオフラインで再起動できることは別。
- iOS／Androidアプリ：ゲーム本体を再利用するCapacitorが候補。ネイティブ保存・共有などを追加する。今回はアプリ本体やストア登録を作成していない。
- 大量の菌は、遠くでは場所ごとの個体数として計算し、近くの代表個体を詳細描画する案。台数・FPSは実機測定で決める。

WebKitは背景ページのアニメーションやタイマーが制限されることを説明している。[WebKit](https://webkit.org/blog/8970/how-web-content-can-affect-power-usage/)

CapacitorはWebGLとCanvasを用いたゲームをサポートする。ただし包むだけで速くなる保証ではない。[公式ドキュメント](https://capacitorjs.com/docs/guides/games)

ブラウザの保存データは消去され得るため、今回の書き出し機能を用意。アプリのPreferencesもアンインストール後まで残る保存ではない。[WebKit保存方針](https://webkit.org/blog/14403/updates-to-storage-policy/)、[Capacitor Preferences](https://capacitorjs.com/docs/apis/preferences)
